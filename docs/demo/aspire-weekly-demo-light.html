CVE-2026-45659 · critical · Microsoft SharePoint Server Deserialization of Untrusted Data Vulnerability
Microsoft SharePoint Server · Due date passed · 🔴 RANSOMWARE
Microsoft SharePoint Server contains a deserialization of untrusted data vulnerability which allows an authorized attacker to execute code over a network. The federal remediation date has already passed.
Source
CVE-2026-72529 · high · TrueConf Server Missing Authentication for Critical Function Vulnerability
TrueConf Server · Due in 1d (2026-08-23)
TrueConf Server contains a missing authentication for critical function vulnerability which could allow a remote unauthorized attacker with network access via port 4307/TCP to execute an arbitrary script. Federal agencies must remediate within 1 day.
Source
CVE-2026-73570 · high · Zimbra Collaboration Suite (ZCS) OS Command Injection Vulnerability
Synacor Zimbra Collaboration Suite (ZCS) · Due in 2d (2026-08-24)
Zimbra Collaboration Suite (ZCS) contains an OS command injection vulnerability which could allow an unauthenticated attacker to send specially crafted SMTP requests that may result in execution of arbitrary operating system commands as the Zimbra user. Federal agencies must remediate within 2 days.
Source
CVE-2026-72530 · high · TrueConf Server Code Injection Vulnerability
TrueConf Server · Due in 12d (2026-09-03)
TrueConf Server contains a code injection vulnerability that could allow an unauthorized remote attacker with network access via port 4307/TCP to use a specially crafted script to break out of the isolated environment and execute arbitrary code on the host system. Federal deadline: 2026-09-03.
